Apple Health sync

A web page can't read Apple Health, so an iPhone Shortcut reads it and sends the numbers to Rhythm Log every night. Anything typed by hand in the app is never overwritten. The Shortcuts app's Health actions look a little different between iOS versions. If a step doesn't match what you see, send a screenshot and we'll adjust.

Part 1: Turn on the sync (one time, on a computer or any phone)

  1. In Cloudflare, open the smartthings-myq Worker, then Settings, then Variables and Secrets, then Add.
  2. Type: Secret. Name: INGEST_TOKEN. Value: a long made-up code of 20 or more characters, for example four random words with dashes. Save it and deploy if asked. Keep a copy somewhere safe.
  3. On her phone, open Rhythm Log, go to More, paste the same code under Apple Health sync, and tap Save code.

Part 2: Build the shortcut (her iPhone, Shortcuts app)

Tap + to make a new shortcut named Send to Rhythm Log, then add these actions in order:

  1. Current Date, then Format Date with Date Format set to Custom and the format yyyy-MM-dd. Call the result Today.
  2. Find Health Samples: Type Steps, Start Date is today. Then Calculate Statistics: Sum. Call it Steps.
  3. Find Health Samples: Type Exercise Minutes (may be called Apple Exercise Time), Start Date is today. Calculate Statistics: Sum. Call it Exercise.
  4. Find Health Samples: Type Sleep, End Date is today, Value is one of Asleep, Core, Deep or REM (not In Bed or Awake). Calculate Statistics: Sum of duration. Convert it to hours and call it Sleep.
  5. Find Health Samples: Type Resting Heart Rate, sort by Start Date newest first, limit 1. Call it RHR. Do the same for Heart Rate Variability and call it HRV. These two are optional.
  6. Get Contents of URL:
    • URL: /api/ingest
    • Method: POST
    • Headers: add Authorization with the value Bearer followed by the sync code (note the space after Bearer)
    • Request Body: JSON, with these fields:
      KeyValue
      dateToday (text)
      stpSteps (number)
      exmExercise (number)
      shSleep in hours (number)
      rhrRHR (number, optional)
      hrvHRV (number, optional)
  7. Run it once with the play button. The response should say "ok": true. Then open Rhythm Log, go to More, tap Sync now, and check that today's card shows "from Health" next to the numbers.

Part 3: Run it automatically

  1. In Shortcuts, go to Automation, tap +, then Time of Day. Pick about 10:00 PM, Daily.
  2. Choose Run Shortcut and select Send to Rhythm Log. Set it to Run Immediately and turn off Notify When Run.

She can also run the shortcut by hand any time to push fresh numbers.

Things to check on the first few days

  • Steps too high? Raw samples from the iPhone and the Watch can both be counted. Compare with the Health app. If the total is too high, add a filter to Find Health Samples so Source is the Apple Watch only.
  • Sleep score: Apple's own Sleep Score doesn't appear to be readable by Shortcuts. If a Sleep Score type shows up in the Health sample list, add it as ss. Otherwise she can type it in and the app keeps it.
  • Nothing arrives: the app's More tab shows when it last synced, and says if the code was rejected.
